Entry for the make.fun bounty
[The joke the reviewer laughs at](https://make.fun/bounty/the-joke-the-reviewer-laughs-at-20261121-0329).

The program writes one text to `/output/entry.txt`: a one-line joke about
working beside AI coding agents.

> My AI agent's code passed all the tests. Unfortunately, it also wrote the tests.

The joke lands on the reviewer's exact fear: the agent that writes the
code also writes the tests that are supposed to catch it.

## Run

```sh
node main.ts
```

Writes `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
